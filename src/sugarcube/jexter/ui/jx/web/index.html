Everything this window does also works without it: from your own Java program, or from a command line — the way to run Jexter unattended. You need the Jexter jar (here sugarcube-jexter.jar; use the name of the file you received) and Java 21 or newer.

In your Java code


    

    
One call: it writes the normalized PDF to the second file and returns the
       OCDDocument (page count, etc.). It throws an IOException when the PDF cannot be read.


    
 Command line — a file or a folder

    

      
      

    


    
 Command line — hot folder

    
Watches a folder and normalizes every PDF placed in it, until stopped with Ctrl-C. No window,
       no browser permission: the right choice for production, e.g. as a scheduled task that starts with the machine.

    

      
      

    


    
 Options

    

      
--suffix=<s>Name ending of the results: report.pdf → report<s>.pdf. Default -normalized. Empty (--suffix=) keeps the name — only allowed with a separate output folder.

      
--done[=<dir>]After each result is written, move the original: a name is a sub-folder of the input folder (default Done); a full path (--done=D:\Archive) is that folder. Sub-folders are reproduced there.

      
--recursiveInclude sub-folders; with an output folder, the sub-folder tree is reproduced there.

      
--threads=<n>PDFs converted at once. Default: half the processor cores, at most 3.

      
--interval=<sec>Hot folder: how often to look for new PDFs. Default 2 seconds.

      
--outlineDraw the text as shapes instead of a selectable text layer.

    


    
The command line does not read this window's Settings: pass
      the options you need. A PDF that is re-delivered under the same name is normalized again, in the window and on the command line.

    
The normalization itself is fixed — nothing to configure:
      the text layer is rebuilt, bookmarks are added only when the PDF has none, links and annotations are kept,
      running headers and footers are left as they are.

Hot folder

    
Click Hot folder… on the main screen and pick a folder:
      every PDF placed in it is normalized automatically, as long as this window stays open. Results are saved as set
      above. A PDF delivered again under the same name is normalized again.

Include sub-folders

        

      

      
PDFs in sub-folders are normalized too; with Next to the original,
        each result stays in its own sub-folder.

      

        
Move originals to

        

      

      
Once its normalized PDF is saved, the original moves into this sub-folder of the
        watched folder — type any name — so what remains is what is still to do. To move originals to a folder
        elsewhere, use the command line: --done=D:\Archive.
