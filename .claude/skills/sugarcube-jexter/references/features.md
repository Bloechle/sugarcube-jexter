# Feature matrix — catalog & ground-truth schema

28 synthetic PDFs, each isolating ONE trait. Generated by
`test/fixtures/generate_matrix.py` (in the repo; CI builds and gates them on every push) (deterministic: reportlab `invariant=1` + fixed metadata).
Each carries declared truth in `manifest.json`.

## Manifest `expected` schema

Per entry, an `expected` block the verifier checks against extracted facts:

| key | meaning | checked on stages |
|-----|---------|-------------------|
| `pages` | page count | all |
| `page_size_pt` | `[w,h]` of page 0 (pt) | pdf, ocd |
| `text_contains` | substrings that MUST be extractable | all |
| `fonts_embedded` | ≥1 embedded font expected | pdf, ocd |
| `fonts_not_embedded` | named fonts must NOT be embedded | pdf, ocd |
| `colorspaces` | device/Separation spaces present | pdf, ocd |
| `images` | `[{colorspace,bpc}]` expected | pdf, ocd |
| `raw_tokens` | operator/dict tokens (`/Separation`, `3 Tr`, `W* n`…) | pdf only |
| `info` | Info dict `title`/`author` | pdf, ocd |

`raw_tokens` use ` || ` for alternatives (e.g. `W* n || W n`). Operator-level
tokens are PDF-specific and auto-skipped (reported) on OCD/EPUB stages.

## Catalog

### fonts

- **`text_base14`** — Standard 14 fonts. Base-14 fonts must NOT be embedded; relies on viewer fonts.
  - checks: not-embedded:Helvetica,Times,Courier
- **`text_embedded_ttf`** — Embedded TrueType. Subsetted TrueType, embedded with ToUnicode CMap.
  - checks: embedded:DejaVu (TrueType)
- **`text_cjk_cid`** — Embedded CJK (CIDFontType2). Type0 composite font, CIDFontType2 (TrueType). For a pure CFF/Type1C sample use the fetched corpus (cff_text).
  - checks: embedded:CJK (TrueType CID)
- **`text_unicode`** — Unicode multi-script. Multi-script BMP; checks ToUnicode round-trip.
  - checks: embedded:DejaVu (TrueType)
- **`text_rtl`** — RTL scripts. RTL stored in logical order; ReportLab does NOT do bidi/shaping. Tests how the consumer handles RTL + presentation forms.
  - checks: embedded:DejaVu (TrueType)

### text

- **`text_rotated`** — Rotated text. Text matrices with rotation; checks geometry recovery.
  - checks: embedded:DejaVu (TrueType)
- **`text_render_modes`** — Text render modes. Mode 3 = invisible text (OCR layer): must extract but not show.
  - checks: embedded:DejaVu (TrueType); tokens:3 Tr,1 Tr,2 Tr
- **`text_tiny_leading`** — Tiny font / tight leading. Leading < font size -> overlapping baselines; line-grouping stress.
  - checks: embedded:DejaVu (TrueType)

### vector

  - checks: tokens:cm

- **`vector_gradient`** — Axial+radial shadings. Type 2 (axial) and Type 3 (radial) shadings.

- **`vector_dash_caps`** — Dashes/caps/joins. setDash/setLineCap/setLineJoin -> d/J/j operators.

### color

- **`color_rgb`** — DeviceRGB. rg/RG operators.
  - checks: cs:DeviceRGB; tokens:rg
, rg
- **`color_cmyk`** — DeviceCMYK. k/K operators.
  - checks: cs:DeviceCMYK; tokens:k
, k
- **`color_spot`** — Spot/Separation. Genuine Separation color space with Type-2 tint transform to DeviceCMYK.
  - checks: cs:Separation; tokens:/Separation,PANTONE-1655-C,cs,sc
- **`color_alpha`** — Alpha/transparency. Constant fill alpha -> ExtGState /ca; overlapping translucency.
  - checks: tokens:/ca ,/ca

### image

- **`image_jpeg_rgb`** — RGB JPEG. Baseline JPEG, DeviceRGB.
  - checks: img:{'colorspace': 'rgb'}; tokens:/DCTDecode
- **`image_png_alpha`** — PNG alpha (SMask). Soft mask alpha over a colored background.
  - checks: img:{'colorspace': 'rgb'}; tokens:/SMask
- **`image_cmyk_jpeg`** — CMYK JPEG. CMYK JPEG; many tools mishandle Adobe-inverted CMYK.
  - checks: img:{'colorspace': 'cmyk'}; tokens:/DCTDecode
- **`image_1bit`** — 1-bit bilevel. 1 bit-per-component bilevel raster.
  - checks: img:{'bpc': 1}
- **`image_svg_vector`** — SVG -> vector. SVG rendered as native PDF vector ops, NOT a raster image.
  - checks: tokens:re, c


### page

- **`page_mixed_sizes`** — Mixed page sizes. Three pages, three different MediaBox sizes.
- **`page_rotate`** — /Rotate 90. Page /Rotate attribute = 90; visual vs logical orientation.
  - checks: tokens:/Rotate
- **`page_mediabox_cropbox`** — MediaBox != CropBox. CropBox != MediaBox; effective page area differs from media.
  - checks: tokens:/CropBox

### doc

- **`doc_outline_links`** — Outline + links. Document outline (bookmarks) + external URI + internal GoTo links.
  - checks: tokens:/Outlines,/Link,/URI
- **`doc_metadata_xmp`** — Metadata. Document Info dictionary metadata; check title/author extraction.

## Known generator limitations

- **CFF/Type1C not embeddable by reportlab** → `text_cjk_cid` uses a TrueType CJK
  font (IPA Gothic → CIDFontType2). For a pure CFF sample, pull one from the corpus
  (`pattern_text_embedded_font.pdf`).
- **Spot color**: reportlab 4.x emits no `/Separation`; `color_spot` is built with
  pikepdf (real Separation + Type-2 tint transform to DeviceCMYK).
- **RTL**: no bidi/shaping (logical order) — tests the consumer's handling.
- `page_rotate` / `page_mediabox_cropbox` are post-processed with pypdf.
